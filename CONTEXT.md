# Поиск по каналу Briefly

Этот контекст описывает материалы публичного Telegram-канала @brieflyru, по которым ведётся поиск.

## Язык

**Сообщение**:
Отдельная запись ленты @brieflyru с собственным ID в Telegram. Каждая фотография альбома является отдельным сообщением.

**Пост**:
Публикация канала с непустым видимым текстом: отдельное сообщение (в том числе фото или видео с подписью и пересланное из другого канала) или альбом, показанный с общим текстом. Служебные сообщения, опросы и публикации без текста постов не образуют.

**Статья**:
Материал Briefly, являющийся единицей поиска и состоящий из одного или нескольких постов.

**Альбом**:
Группа фотографий канала, показанная клиентом Telegram как один блок, но состоящая из отдельных сообщений. Общая подпись показывается под альбомом, только если она есть ровно у одной фотографии. В веб-ленте альбом — один блок веб-ленты.

**Блок веб-ленты**:
Одна публикация в веб-ленте канала `t.me/s` с одним ID. Для отдельного сообщения это его ID; для альбома — ID первой фотографии, а ID остальных фотографий указаны внутри блока. Одна строка `raw_posts` — один блок веб-ленты.
_Avoid_: пост (так называется результат нормализации)

**Составная статья**:
Статья, текст которой редакция разделила на пронумерованные части; каждая часть представлена одним постом. Номер может отсутствовать у первой части, если следующая часть отвечает на неё. Несколько фотографий одного альбома сами по себе не образуют составную статью.
_Avoid_: multipart-пост.

**Неполная статья**:
Составная статья, у которой в собранных данных не хватает части: меньше постов, чем объявленное общее число частей, или пропуск в номерах. Составная статья без объявленного общего числа, пронумерованная подряд с первой части, неполной не считается.
_Avoid_: статья с неизвестной полнотой

**Повторная публикация**:
Тот же материал, опубликованный каналом снова через дни или месяцы. Образует отдельную статью; части разных публикаций между собой не склеиваются.
