# Поиск по каналу Briefly

Этот контекст описывает материалы публичного Telegram-канала @brieflyru, по которым ведётся поиск.

## Язык

**Сообщение**:
Отдельная запись ленты @brieflyru с собственным ID в Telegram. Каждая фотография альбома является отдельным сообщением.

**Пост**:
Текстовая публикация канала, полученная из отдельного сообщения с текстом или из фотоальбома с ровно одной подписью. Альбом без общей подписи не образует пост.

**Статья**:
Материал Briefly, являющийся единицей поиска и состоящий из одного или нескольких постов.

**Альбом**:
Группа фотографий канала, показанная клиентом Telegram как один блок, но состоящая из отдельных сообщений. Общая подпись показывается под альбомом, только если она есть ровно у одной фотографии.

**Составная статья**:
Статья, текст которой редакция разделила на явно обозначенные части; каждая часть представлена одним постом. Несколько фотографий одного альбома сами по себе не образуют составную статью.
_Avoid_: multipart-пост.

**Неполная статья**:
Статья с объявленным общим числом частей, для которой в собранных данных отсутствует хотя бы одна часть.

**Статья с неизвестной полнотой**:
Статья с пронумерованными частями без объявленного общего числа частей; по имеющимся постам нельзя определить, опубликовано ли продолжение.
