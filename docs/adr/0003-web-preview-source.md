# Основной источник — веб-лента `t.me/s`, в `raw_posts` лежит HTML блока

Основной источник части 1 — публичная веб-лента `https://t.me/s/<канал>` вместо MTProto. Создать приложение на my.telegram.org и получить `api_id`/`api_hash` сейчас нельзя из-за бага Telegram. Веб-лента же читает всю доступную историю `@brieflyru` без аккаунта и листается так же, как `messages.getHistory`: `?before=N` — исключающая верхняя граница ([заметка о веб-ленте](../research/telegram-web-preview.md)).

Строка `raw_posts` соответствует **блоку веб-ленты**, а не каждому сообщению Telegram. Альбом — одна строка с ID первой фотографии; ID остальных фото остаются внутри HTML. `payload` — сырой HTML блока, `{"html": "<div class=\"tgme_widget_message …\">…</div>"}`, с `payload_schema = "t.me/s html v1"`.

Смысл [ADR-0001](0001-decoded-telegram-payload.md) сохраняется: храним исходник целиком, а не извлечённые поля, чтобы правила нормализации менялись без повторной загрузки.

## Considered Options

- **Разобранный JSON** (текст, дата, просмотры, ID фото альбома) вместо HTML. Отвергнут: всё, что парсер не извлёк, терялось бы навсегда, а разметка ленты не документирована.
- **Строка на каждое фото альбома**, как у MTProto. Отвергнута: у отдельных фото в ленте нет своего блока, и загрузчику пришлось бы выдумывать их содержимое, нарезая блок.
- **Подождать починки my.telegram.org.** Отвергнуто: срок неизвестен, а веб-лента покрывает нужды части 1.

## Consequences

- **MTProto отложен, а не отменён.** Готовая реализация сессии и `login` лежит в PR #13 (черновик), источник на `grammers` — #8. Когда создание приложений починят, MTProto станет второй реализацией `HistorySource`. Его строки отличаются по `payload_schema`, и для них действует ADR-0001. Таблица `telegram_session` остаётся в схеме для него.
- **В данных нет `grouped_id`, TL-объекта и метаданных медиа**, а текст приходит уже с HTML-разметкой. Нормализатор разбирает HTML; альбом он получает готовым блоком.
- **Лента показывает текущее состояние поста** (правленный текст с пометкой `edited`, текущие просмотры). Сохраняется то, что было при первом чтении, как и раньше.
- **Пустая лента — начало канала только при явном признаке** (`tme_no_messages_found` в блоке ленты). Любой другой ответ без постов — ошибка источника, иначе проход завершился бы поверх незагруженной истории.
