# Анализ загруженной истории @brieflyru для нормализатора

Решения по его итогам — в [плане нормализатора](../normalizer-plan.md) и [ADR-0004](../adr/0004-normalization-full-recompute.md).

Ответы на вопросы, поставленные до загрузки истории, по `raw_posts` на 2026-10-24: 44 127 **блоков веб-ленты**, ID 1…48 274, первый проход завершён (`newest_fetched_id = 48274`), все строки `payload_schema = "t.me/s html v1"`. Анализ выполнен однократно скриптами только на чтение; доли и примеры ниже — по этому срезу. Ссылки ведут на `t.me/brieflyru/<ID>`.

## Главное

- **Источник изменил задачу альбомов.** Гипотезы писались для MTProto (строка = сообщение, `grouped_id`). В веб-ленте альбом — одна строка с одним общим текстом; сопоставлять фото по строкам и пересчитывать альбом при появлении новых фото не нужно.
- **Составные статьи массовые:** 11 927 блоков (27 %) несут маркер части в заголовке, из них собирается ~4 600 статей.
- **Редакционная нумерация шумная:** опечатки в номерах и общем числе, разные формулировки заголовка у частей одной статьи, повторные публикации того же материала через месяцы, регулярные рубрики с одинаковым заголовком. Склейка по точному совпадению заголовка дробит статьи; последовательная склейка «часть n−1 → n» в окне 24 ч с нестрогим сравнением заголовков оставляет ~100 аномалий на ~4 600 статей.
- **Полный пересчёт дешёвый:** разбор HTML всех блоков на Rust (`scraper` 0.27, один поток, вместе с JSON) — 2,6 с.

## Редакционная нумерация частей

Маркер ищется в первой строке текста (заголовке), номер 1–30; последний маркер строки.

| Форма | Частей | Пример |
| --- | ---: | --- |
| `Часть N/M` (`Часть 1/3.`, `Часть 2/3`) | 5 206 | [29071](https://t.me/brieflyru/29071) |
| `Часть N` без общего числа (`Часть 1.`, `Часть 2:`, `(часть 1):`) | 6 721 | [5275](https://t.me/brieflyru/5275), [4687](https://t.me/brieflyru/4687) |
| `(N/M)` в скобках | 1 | [36844](https://t.me/brieflyru/36844) |

- Общее число частей: 2 — 3 453, 3 — 1 127, 4 — 382, 5 — 130, 6–10 — 114.
- В 423 случаях текст продолжается в той же строке после маркера (`Лоуренс Фридман (часть 2): Именно вопрос…`), заголовок — только то, что до маркера.
- Слова «Продолжение», «Окончание», «см. выше» как маркеры частей не используются.
- Ложные срабатывания нестрогого шаблона: «оставшуюся часть 2023 года» ([3661](https://t.me/brieflyru/3661)), «пятая часть мировых запасов» — отсекаются условием «маркер в заголовке, номер ≤ 30».
- Регистр: `Часть` — 11 776, `часть` — 148 (`(часть 2)`, `…, часть 1/2.`); `ЧАСТЬ`, `Ч.`, `Part`, латинские буквы-двойники не встречаются.
- Множественное «части N» маркером не бывает: «большей части 26 июля» ([6652](https://t.me/brieflyru/6652)), «части 10-го корпуса» ([7016](https://t.me/brieflyru/7016)), «части 25-й армии» ([9777](https://t.me/brieflyru/9777)), «Части 1-10» ([16399](https://t.me/brieflyru/16399)). Цифры выше по тексту получены шаблоном `част[ьи]` и включают эти 4 ложных срабатывания.
- Номер с порядковым окончанием — не маркер: «ключевую часть 21-го пакета» ([44349](https://t.me/brieflyru/44349)).

Одинаковый номер подряд во всех 15 случаях — опечатка, а не конкурирующие версии: тексты разные и продолжают друг друга. Одинаковый заголовок с разницей больше 3 ч с тем же номером ни разу не оказался продолжением.

### Близость частей

- Интервал между соседними частями: медиана 27 мин, p90 52 мин, p99 84 мин, максимум ~24 ч.
- Чужие блоки между первой и последней частью: нет — 3 862 статьи, 1 — 476, 2 — 74, 3 и больше — 45. Соседство по ID частей не гарантирует.

### Результат склейки

Правило-кандидат: часть `n > 1` присоединяется к последней открытой статье, у которой последняя часть имеет номер `n − 1`, опубликована не более 24 ч назад и имеет сходство нормализованного заголовка (без регистра, кавычек, `*`, пунктуации; `difflib` ratio) не ниже порога.

| Итог | Порог 0,9 | Порог 0,6 |
| --- | ---: | ---: |
| Статей | 4 650 | 4 622 |
| С общим числом, все части на месте | 2 210 | 2 222 |
| Без общего числа, части 1…k подряд | 2 339 | 2 339 |
| С общим числом, части не хватает | 61 | 37 |
| Начинается не с части 1 | 40 | 24 |

Остаток аномалий объясняется опечатками в номерах, первой частью без маркера и переформулированными заголовками; полностью неполных статей (часть действительно не опубликована) по выборке почти нет. Без общего числа части — половина составных статей: при принятом в гипотезах статусе почти все они получили бы **«неизвестную полноту»**.

## Время полного пересчёта

Разбор HTML всех 44 127 блоков (JSON + `scraper::Html::parse_fragment` + выборка текста) — 2,6 с в release-сборке на одном потоке. Чтение 324 МБ `payload` из PostgreSQL и запись ~40 тыс. постов и статей добавят секунды, но не порядок величины.
